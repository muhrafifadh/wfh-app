Record actual or suspected attendance misuse here. Turning on location or selfie checks for an organization needs documented justification, and this log is where it comes from.

## Rules

- **Facts only.** Record what was observed and how. Never fabricate an entry, and never record fraud as established without evidence: "suspected" until a person has reviewed it.
- **No personal data in this file.** It is in a Git repository. Use the organization and an internal case reference kept by Admin/HR, never names, employee numbers, locations or photos.
- **One row per incident.** Update the outcome when the review finishes, including "not misuse".
- **Historical incidents aren't required** to build the optional infrastructure, only to turn a method on.
